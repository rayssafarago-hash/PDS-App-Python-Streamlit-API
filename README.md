# PDS-App-Python-Streamlit-API - Quiz Open Trivia DB

Projeto desenvolvido em Python com Streamlit utilizando a API pública Open Trivia DB.

## O que o aplicativo faz

O usuário pode escolher a quantidade de perguntas, a categoria e a dificuldade do quiz.

O aplicativo usa a API do Open Trivia DB, mostra a perguntas o usuário escolha e mostra a pontuação final.

## API utilizada

Open Trivia DB:
https://opentdb.com/api.php


## Como executar

1. Instale as dependências:

pip install -r requirements.txt


2. Execute o aplicativo:


streamlit run app.py
